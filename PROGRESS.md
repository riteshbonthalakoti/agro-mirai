## Locked decisions

| # | Decision | Rationale |
|---|---|---|
| 1 | CLI-first for all external services | Reproducibility, auditability, no undocumented dashboard state |
| 2 | Additive-only data contracts | Prevent breaking downstream modules once contracts are published |
| 3 | SQLite (dev) / Supabase Postgres (prod) via repository interface | Decouple modules from a specific DB engine |
| 4 | GEE live with local NDVI cache fallback | Keep the system usable when Earth Engine is unreachable |
| 5 | Strict module dependency gating (N+1 after N is tested + committed) | Keep the build linear and verifiable for a capstone timeline |
| 6 | Entity IDs are UUIDv4 strings | Portable across SQLite/Postgres, no coordinator, no leaked record counts — `decisions/0002-id-format.md` |
| 7 | Single-farmer-account-per-user (no multi-tenancy) | Matches the PPT's scope; prevents later modules inventing ad-hoc org/role models — `decisions/0003-single-farmer-tenancy.md` |

- **05-processing**: done

Feature engineering layer implemented: specs/core/features.md documents
every feature (weather rolling aggregates over 7/14/30-day windows,
soil pass-through + derived NPK balance index, NDVI latest/trend/source,
season/days-since-sowing from sown_on) plus an explicit missing-data
policy. FeatureBuilder (src/agro_mirai/processing/feature_builder.py) is
a pure function of a Field_ plus plain WeatherReading/SoilSample/
NDVIReading lists and an as_of date — no DataStore calls, no network,
no datetime.now(). Weather is required (raises ValueError if empty);
soil and NDVI are optional with explicit *_data_available flags and
None-propagation, never a silent 0.0.

15 tests in tests/processing/test_feature_builder.py cover full data,
missing NDVI (both synthetic and loaded from the new farm-002.json
fixture), missing soil, weather-only, the zero-weather error, and the
season-mapping boundaries. farm-002.json is a second golden fixture
(new farmer/field, weather+soil but empty ndvi_readings) validated via
`python tools/check_specs.py --fixture specs/domains/fixtures/farm-002.json`.
